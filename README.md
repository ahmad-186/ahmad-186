### What I do

I build voice and chat AI agents that sit inside a business's actual workflow instead of bolting a chatbot on top of it — order tracking, appointment booking, missed-call recovery, cart recovery, and support triage, engineered for the failure points that don't show up in a demo.

Two tracks, same underlying skill set:
- **Agency work** at Neme Automation — client-facing voice receptionists, WhatsApp support agents, and workflow automation, mostly delivered through n8n
- **Independent AI engineering** — LangGraph-based agent systems, RAG pipelines, and full-stack builds, learning in public as I go
