## 🚀 Featured Projects — Agentic AI Systems

### 🤖 [WhatsApp Customer Support Agent](https://github.com/ahmad-186/Whatsapp-CustomerSupportChatbot-LangGraph)
Production-style AI support agent on WhatsApp Cloud API — handles FAQs (RAG), Shopify order tracking, product recommendations, and human ticket handoff. Modular LangGraph state machine with persistent conversation memory in PostgreSQL, FastAPI backend, Dockerized and deployed on Render.
`LangGraph` `LangChain` `Mistral AI` `FastAPI` `PostgreSQL` `Shopify API` `Docker`

### 📊 [Self-Correcting SQL Analytics Agent (InsightAI)](https://github.com/ahmad-186/self-correcting-sql-analytics-agent)
Full-stack natural-language-to-SQL analytics app. LLM-generated SQL is never trusted blindly — a schema-aware generation → validation (SQLGlot) → self-correction loop catches and fixes bad queries before execution, then produces executive summaries and auto-recommended visualizations. React dashboard + FastAPI backend.
`LangGraph` `FastAPI` `React` `PostgreSQL` `SQLGlot` `Docker Compose` `Render`

### ✈️ [TripMate AI — Multi-Agent Travel Planner](https://github.com/ahmad-186/TripMate-AI-A-multi-Agent-Travel-Planner)
Multi-agent trip planner coordinating a flight-search agent, hotel-research agent, itinerary agent, and response agent through a LangGraph workflow. Turns a single natural-language request into flights, hotels, and a day-by-day plan.
`LangGraph` `LangChain` `Groq` `FastAPI` `PostgreSQL` `Tavily API` `AviationStack API`

### 🎓 [CampusBrain AI](https://github.com/ahmad-186/CampusBrain)
RAG system for answering questions over university course materials — PDF ingestion, chunking, embedding generation, and ChromaDB-backed retrieval for question answering.
`RAG` `ChromaDB` `Python`
